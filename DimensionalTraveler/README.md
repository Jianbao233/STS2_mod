# 次元旅人

《杀戮尖塔 2》角色 Mod 的 `0.1.0` 单人纵切原型。当前目标是先闭合炼金、药剂背包和战后奖励流程，再扩展完整卡池、多人同步与美术资源。

## 当前状态

安全基线：`60644f2`（`Add DimensionalTraveler vertical slice prototype`）。

### 已实现

- 次元旅人角色、12 张起始普通卡和起始遗物。
- 生机、挥发、腐化三类战斗期炼金原理。
- 战斗期药剂背包，以及永久系统牌 `药剂包`。
- 5 种起始药剂的普通与精制模型。
- 炼成、提纯、升华和从背包取药流程。
- 中英文角色、卡牌、能力、遗物与悬浮提示本地化。

### 已验证

- DLL、PCK 与 manifest 已构建并部署，源码产物、`torelease` 和游戏加载目录的 SHA-256 一致。
- RitsuLib 自动注册结果为 40 项成功、0 项失败；中英文 12 份本地化表均成功合并。
- 生机、挥发、腐化计数器可见且图标可区分，中文悬浮说明与获得反馈均可触发。
- 三原理的战斗开始、回合开始、生产、支付、无硬上限与跨战斗重置规则均已完成运行验证。
- 护盾药剂已完成“炼成 → 入包 → 提纯 → 原生界面取出 → 指定自身使用”的运行链路。
- 第一、第二场战斗均可进入奖励界面，卡牌奖励可生成并跳过，之后可返回地图并进入后续节点。

### 尚未完成

- 自卫、攻击、腐化、挥发过牌 4 种起始药剂尚未完成逐项手动目标与效果验证。
- 普通 → 精制、普通+ → 精制+ 的升华链路尚未完成运行验证。
- KitLib `0.27.0` 的自动出牌器只解析原生 `TargetType`，无法为 RitsuLib 自定义 `Anyone` 目标类型传入目标；此类药剂必须使用真实游戏交互验收。
- 多人同步、队友目标、杰作药剂与特殊炼金原理不属于当前纵切验收范围。

## 依赖边界

- **运行时依赖**：已订阅的 `STS2-RitsuLib`，兼容游戏 `0.108.0` 分支。
- **测试基础设施**：实际加载 KitLib `0.27.0`（部署 DLL SHA-256：`0E18BB2D353AE19A76F868C2B7D0D05171C41279A56D5F6C4D345FDE18727700`）用于游戏内调试与自动化验证；本地源码参考点为 `38743dd`，不作为部署 DLL 的来源证明。KitLib 不是本 Mod 的运行时依赖。

## 源码职责

- `src/Alchemy/Backpack/`：药剂背包状态、选择流程和系统牌保护。
- `src/Content/`：卡牌、能力、遗物及角色卡池模型。
- `src/Resources/`：炼金原理的注册、获取与支付。
- `src/Bootstrap/`：RitsuLib 与内容程序集初始化。
- `DimensionalTraveler/localization/`：英文与简体中文本地化。

## 本地构建与部署

运行以下命令会编译 DLL、导出 PCK，并同步到项目 `torelease/` 和游戏的 `mods/DimensionalTraveler` 目录。

```powershell
.\build.ps1
```

构建缓存、PCK、`torelease/`、`release/` 和 `_runtime_*` 运行截图均不纳入 Git。
